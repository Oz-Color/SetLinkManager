# Set Link Manager — downloads

Set Link Manager checks and configures **Set Link Nano** Wi-Fi HaLow units. By Oz Color.

**Download:** the latest version is under [Releases](../../releases/latest). Open the `.dmg`, then open Set Link Manager: it offers to move itself to Applications. macOS 15 or later, Apple silicon and Intel.

Installed copies update themselves: the app checks once a day and asks before installing.

This repository holds only the signed, notarised app and its update feed (`appcast.xml`, read by the app). Support: use **Support** inside the app.
